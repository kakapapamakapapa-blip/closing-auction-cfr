# Forgetting Without Loss: CFR in Closing Auctions

Code and result files for the article "Forgetting Without Loss: Smaller Strategy Tables for Counterfactual
Regret Minimization in Closing Auctions" (A. Amirtay, Astana IT University, 2026).

- `python/` - auction games (instances A, B, C), CFR, sampled CFR, exact best responses, all experiments
  (Python 3.13, NumPy 2.5, Matplotlib 3.11). See `python/README.md` for the command behind each table and figure.
- `simulator/` - C simulator with the full Nasdaq Closing Cross timetable (330 imbalance publications) and
  outcome-sampling CFR. Build: `gcc -O3 -march=native -pthread -o ncc3 ncc2.c -lm`. See `simulator/README.md`.
- `results/` - JSON result files behind every number in the article.

Install: `pip install -r requirements.txt`. All data are generated by simulation; no market data are used.
